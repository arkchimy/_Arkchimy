[오늘 논의한 설계 결정들]

1. SYN flood 재현 방식 (왜 non-blocking + 즉시 close인가)
   - 처음엔 "handshake 완료 확인 후 close"(select/WSAPoll)로 가려 했으나,
     유저가 핵심을 짚음: "실제 SynFlood는 3way가 안 끝난 채로 끊는 거 아니야?"
   - 결론: blocking/non-blocking 여부는 커널이 SYN을 보내는 것과 무관함
     (둘 다 커널이 SYN을 보냄; 차이는 "완료를 기다리는 방식"일 뿐).
     진짜 SYN flood는 애초에 handshake를 끝내지 않는 것 - SYN만 보내고
     마지막 ACK를 안 보내서 서버의 backlog half-open 슬롯을 점유시킴.
   - 그래서 설계 확정: non-blocking connect() 호출 후, handshake 완료
     여부를 "확인하지 않고" 바로 closesocket() → 로컬 TCB가 그냥 삭제되고
     ACK는 영원히 안 나감. raw socket/스푸핑 없이도 같은 효과를 냄.
   - 유저가 직접 패킷 드랍 프로그램으로 ACK 차단 환경에서 검증하기로 함.

2. 클라이언트도 SO_LINGER(0) 필요한 이유
   - connect 성공 후 클라이언트가 먼저 close하면 active closer가 되어
     TIME_WAIT에 들어감 (로컬 임시 포트 고갈 위험).
   - 로컬(127.0.0.1) 테스트에서는 RTT가 거의 0이라 close 호출 전에
     handshake가 이미 끝나버리는 레이스가 실제로 발생할 수 있음 - 이 경우를
     대비해 클라이언트도 SO_LINGER(0)을 걸어 TIME_WAIT 없이 RST로 정리.

3. 서버/클라이언트를 별도 솔루션으로 분리
   - 처음엔 "mode=flood"로 같은 exe에서 돌리려 했으나, 유저가
     "클라이언트와 서버가 분리된 솔루션으로 나오게 해달라"고 정정.
   - D:\_Arkchimy\FloodClient 에 독립된 FloodClient.sln/.vcxproj 생성
     (예전 DummyClient.sln과 동일 패턴 - ParserLib을 ProjectReference로 공유).

4. 워커 스레드 동시 시작 (바리어 + 's' 키 게이트)
   - 문제: 스레드를 for문으로 하나씩 생성하면 먼저 만들어진 스레드가
     나중 스레드보다 먼저 플러딩을 시작해버림.
   - 해결: 각 워커가 시작 직후 mReadyCount를 증가시키고, 그 값이
     mThreadCnt에 도달할 때까지 스핀 대기 → 마지막 워커가 증가시키는
     순간 전부 동시에 통과 (바리어).
   - 별도로, 사람이 준비(패킷 드랍 프로그램 켜기 등)를 마칠 시간을 주기 위해
     main()에서 client.init() 호출 자체를 'ㅅ' 키(소문자 's') 입력 대기
     뒤로 미룸. 바리어(스레드 간 동기화)와 키 게이트(사람 신호)는 역할이 다름.

5. 통계 출력 개선 (tps/avg/total, 라벨링)
   - 처음엔 TPS만 1초마다 출력 → 유저 요청으로 avg(평균) 추가.
   - 평균을 전체 경과시간으로 나누면 "아직 아무 연결도 없던 대기 시간"까지
     분모에 들어가 평균이 낮게 왜곡됨 → 첫 이벤트가 발생한 시점부터만
     경과시간(elapsedSec)을 세도록 수정 (started 플래그).
   - 라벨도 "TPS=" 같은 모호한 표기 대신, 클라이언트는 "연결시도"
     (connect 시도=SYN 보낸 횟수), 서버는 "연결완료"(handshake까지 끝난
     accept 완료 횟수)로 명시. total(누적값)도 같이 출력.
   - **중요 포인트**: 지금 구조에서는 flood 트래픽이 서버의 "연결완료"에
     거의 반영되지 않음 - ACK를 안 보내므로 accept가 완료되지 않기 때문.
     두 TPS를 나란히 비교해도 "클라이언트가 보낸 만큼 서버가 받았는지"를
     보여주지 않음. flood의 실제 영향(backlog 고갈)을 보려면 별도의
     정상 클라이언트로 진짜 connect가 되는지/거부되는지를 봐야 함 (미해결 논의).

6. AcceptExServer 버그 수정 - GQCS 반환값(ok) 미체크
   - 유저가 "AcceptEx에서 연결 끊김을 제대로 확인 못 하는 것 같다"고 지적.
   - 실제 버그 확인: GetQueuedCompletionStatus는 overlapped가 non-null이어도
     ok==FALSE를 반환할 수 있음(= 그 I/O가 에러로 완료됨, 예: handshake
     도중 상대가 RST). 기존 코드는 이걸 안 보고 무조건 ++mAcceptCount 해서
     실패한 연결까지 성공으로 집계하고 있었음.
   - 수정: ok==TRUE일 때만 ++mAcceptCount. (postAccept()의 반환값 체크는
     유저가 "일단 그대로 두자"고 보류 - 근거였던 "flood로 인한 리소스 고갈"은
     유저 지적대로 틀린 논리였음: close-then-reopen 패턴이라 핸들이 쌓이지 않음.
     다만 아주 드문 실패 시 슬롯이 조용히 죽는 문제 자체는 남아있음.)

7. "SYN이 안 나간다" 디버깅
   - 증상: 실제 네트워크에 SYN이 안 보임.
   - 유저 가설(틀림, 하지만 좋은 지적이었음): "클라이언트 소켓에 링거가
     안 걸려서 그런가?" → SO_LINGER는 close 시점의 동작(FIN이냐 RST냐,
     TIME_WAIT 가냐)만 결정하고 connect()가 SYN을 보내는 것 자체와는 무관.
   - 실제로 발견한 건: FloodClient::workerLoop에 SO_LINGER가 전혀 안 걸려
     있었음(합의했던 걸 구현에 빠뜨림) - 이건 고쳤지만 SYN 미전송의
     원인은 아니었을 가능성이 높음.
   - 가장 유력한 원인으로 지목한 것: 이번에 추가한 's' 키 게이트 때문에
     키를 안 누르면 스레드가 전혀 생성되지 않음 (init() 자체가 호출 안 됨).
   - 유저가 "해결됐다"고 확인함 (정확히 뭐였는지는 대화에 명시 안 됐지만
     's' 키 게이트 쪽이었을 가능성이 높음).

#include <WinSock2.h>
#include <ws2tcpip.h>
#include <string>
#include <thread>

#include <atomic>

// 논블로킹 connect() 후 handshake 완료 전에 바로 close - SYN flood 재현용 클라이언트
// ACK를 보내지 않으므로 서버 backlog의 half-open 슬롯을 점유시키는 효과를 냄
class FloodClient
{
public:
	~FloodClient();
	bool init(const std::string& ip, USHORT port, int threadCnt);	// 타겟 주소 설정 + 워커 스레드 시작
	void stop();	// 종료 신호 + join

private:
	void workerLoop();	// { 논블로킹 connect() → 바로 close() } 반복
	void statLoop();	// 1초마다 시도 횟수 콘솔 출력

	sockaddr_in mTargetAddr{};
	int mThreadCnt = 0;
	std::atomic<int> mReadyCount = 0;
	std::vector<std::thread> mWorkers;
	std::thread mStatThread;
	std::atomic<bool> mRunning = false;
	std::atomic<long long> mAttemptCount = 0;
};

#include "FloodClient.h"
#include <cstdio>

FloodClient::~FloodClient()
{
	stop();
}

void FloodClient::stop()
{
	if (!mRunning)
	{
		return;
	}

	mRunning = false;
	for (auto& worker : mWorkers)
	{
		worker.join();
	}
	mStatThread.join();
}

bool FloodClient::init(const std::string& ip, USHORT port, int threadCnt)
{
	mTargetAddr.sin_family = AF_INET;
	mTargetAddr.sin_port = htons(port);
	if (inet_pton(AF_INET, ip.c_str(), &mTargetAddr.sin_addr) != 1)
	{
		return false;
	}

	mThreadCnt = threadCnt;
	mRunning = true;
	for (int i = 0; i < threadCnt; ++i)
	{
		mWorkers.emplace_back(&FloodClient::workerLoop, this);
	}
	mStatThread = std::thread(&FloodClient::statLoop, this);
	return true;
}

void FloodClient::workerLoop()
{
	++mReadyCount;
	while (mReadyCount.load() < mThreadCnt) {}	// 모든 워커가 준비될 때까지 대기 - 마지막 워커가 증가시키는 순간 전부 통과

	while (mRunning)
	{
		SOCKET s = socket(AF_INET, SOCK_STREAM, 0);
		if (s == INVALID_SOCKET)
		{
			continue;
		}

		u_long on = 1;
		ioctlsocket(s, FIONBIO, &on);	// 논블로킹 전환 - connect()가 SYN만 보내고 즉시 반환되게 함

		connect(s, reinterpret_cast<sockaddr*>(&mTargetAddr), sizeof(mTargetAddr));	// handshake 완료 여부는 확인 안 함

		LINGER linger{};
		linger.l_onoff = 1;
		linger.l_linger = 0;
		setsockopt(s, SOL_SOCKET, SO_LINGER, reinterpret_cast<const char*>(&linger), sizeof(linger));
		closesocket(s);	// SYN-SENT 상태에서 즉시 닫음 - 혹시 그 사이 handshake가 끝났더라도 TIME_WAIT 없이 RST로 정리

		++mAttemptCount;
	}
}

void FloodClient::statLoop()
{
	long long last = 0;
	long long elapsedSec = 0;
	bool started = false;
	while (mRunning)
	{
		Sleep(1000);
		long long now = mAttemptCount.load();
		started = started || (now > 0);	// 첫 이벤트가 발생한 뒤부터만 경과 시간을 셈
		if (started)
		{
			++elapsedSec;
		}
		long long avg = started ? now / elapsedSec : 0;
		printf("[FloodClient] 연결시도 tps=%lld avg=%lld total=%lld\n", now - last, avg, now);
		last = now;
	}
}

#include "FloodClient.h"

#include <cstdio>

int main()
{
    WSADATA wsa;
    if (WSAStartup(MAKEWORD(2, 2), &wsa) != 0)
    {
        return 1;
    }

    utility::stDebug debug;
    auto parser = utility::Parser::CreateParser("client.cfg", debug);
    if (parser == nullptr)
    {
        printf("설정 파일 오류 err=%d key=%s\n", debug.err, debug.lastKey.c_str());
        WSACleanup();
        return 1;
    }

    std::string ip;
    USHORT port;
    int threadCnt;
    if (!parser->Get("ip", ip) || !parser->Get("port", port) || !parser->Get("threadCnt", threadCnt))
    {
        printf("설정 키 누락 또는 값 오류 (ip, port, threadCnt)\n");
        WSACleanup();
        return 1;
    }

    printf("'s' 키를 누르면 시작합니다...\n");
    while (_getch() != 's') {}

    FloodClient client;
    if (!client.init(ip, port, threadCnt))
    {
        WSACleanup();
        return 1;
    }
    printf("[main] FloodClient 시작. Enter 입력 시 종료\n");
    system("pause");
    client.stop();

    WSACleanup();
    return 0;
}

#include "AcceptServer.h"
#include "ListenSocket.h"
#include "SocketUtil.h"
#include <cstdio>

bool AcceptServer::init(USHORT port, int backlog)
{
	mListenSock = createListenSocket(port, backlog);
	if (mListenSock == INVALID_SOCKET)
	{
		return false;
	}

	mRunning = true;
	mAcceptThread = std::thread(&AcceptServer::acceptLoop, this);
	mStatThread = std::thread(&AcceptServer::statLoop, this);
	return true;
}

void AcceptServer::stop()
{
	if (!mRunning)
	{
		return;
	}

	mRunning = false;
	closesocket(mListenSock);	// 블로킹 accept()를 깨우기 위해 리슨 소켓을 닫음
	mAcceptThread.join();
	mStatThread.join();	// statLoop는 sleep_for 끝나는 시점에 mRunning 보고 빠져나감
}

AcceptServer::~AcceptServer()
{
	stop();
}

void AcceptServer::acceptLoop()
{
	while (mRunning)
	{
		SOCKET client = accept(mListenSock, nullptr, nullptr);
		if (client == INVALID_SOCKET)
		{
			break;	// 종료 시 리슨 소켓을 닫으면 accept가 에러로 깨어남
		}

		closeReset(client);
		++mAcceptCount;
	}
}

void AcceptServer::statLoop()
{
	long long last = 0;
	long long elapsedSec = 0;
	bool started = false;
	while (mRunning)
	{
		Sleep(1000);
		long long now = mAcceptCount.load();
		started = started || (now > 0);	// 첫 이벤트가 발생한 뒤부터만 경과 시간을 셈
		if (started)
		{
			++elapsedSec;
		}

		printf("[AcceptServer] 연결완료 tps=%lld avg=%lld total=%lld\n", now - last, avg, now);
		last = now;
	}
}

#include "AcceptExServer.h"
#include "ListenSocket.h"
#include "SocketUtil.h"
#include <cstdio>

bool AcceptExServer::init(USHORT port, int backlog, int workerCnt)
{
	mListenSock = createListenSocket(port, backlog);
	if (mListenSock == INVALID_SOCKET)
	{
		return false;
	}

	mIocp = CreateIoCompletionPort(INVALID_HANDLE_VALUE, nullptr, 0, 0);
	if (mIocp == nullptr)
	{
		return false;
	}

	// 리슨 소켓을 IOCP에 등록해야 AcceptEx 완료가 GQCS로 들어온다
	if (CreateIoCompletionPort(reinterpret_cast<HANDLE>(mListenSock), mIocp, 0, 0) == nullptr)
	{
		return false;
	}

	mRunning = true;
	for (int i = 0; i < workerCnt; ++i)
	{
		mWorkers.emplace_back(&AcceptExServer::workerLoop, this);
	}
	mStatThread = std::thread(&AcceptExServer::statLoop, this);

	mAcceptOvs.resize(workerCnt);
	for (int i = 0; i < workerCnt; ++i)
	{
		postAccept(&mAcceptOvs[i]);	// 초기에 워커 수만큼 미리 걸어둔다
	}
	return true;
}

bool AcceptExServer::postAccept(AcceptOv* ov)
{
	SOCKET acceptSocket = socket(AF_INET, SOCK_STREAM, IPPROTO_TCP);
	if (acceptSocket == INVALID_SOCKET)
	{
		return false;
	}

	ZeroMemory(static_cast<OVERLAPPED*>(ov), sizeof(OVERLAPPED));	// 재사용 전 OVERLAPPED 필드 초기화
	ov->mAcceptSocket = acceptSocket;

	DWORD bytesReceived = 0;
	BOOL ok = AcceptEx(mListenSock, acceptSocket, ov->mBuffer, 0,
		sizeof(SOCKADDR_IN) + 16, sizeof(SOCKADDR_IN) + 16, &bytesReceived, ov);

	if (!ok && WSAGetLastError() != WSA_IO_PENDING)
	{
		closesocket(acceptSocket);
		return false;
	}
	return true;
}

void AcceptExServer::workerLoop()
{
	while (true)
	{
		DWORD transferred = 0;
		ULONG_PTR key = 0;
		OVERLAPPED* overlapped = nullptr;
		BOOL ok = GetQueuedCompletionStatus(mIocp, &transferred, &key, &overlapped, INFINITE);

		if (overlapped == nullptr)
		{
			break;	// stop()의 종료 신호
		}

		AcceptOv* ov = static_cast<AcceptOv*>(overlapped);

		if (ok)
		{
			++mAcceptCount;	// handshake까지 완전히 끝난 것만 센다
		}
		// ok == FALSE: handshake 중 연결이 끊어진 것(예: 상대가 RST) - 카운트하지 않고 슬롯만 재사용

		closeReset(ov->mAcceptSocket);
		postAccept(ov);	// 같은 슬롯으로 바로 재등록
	}
}

void AcceptExServer::statLoop()
{
	long long last = 0;
	long long elapsedSec = 0;
	bool started = false;
	while (mRunning)
	{
		Sleep(1000);
		long long now = mAcceptCount.load();
		started = started || (now > 0);	// 첫 이벤트가 발생한 뒤부터만 경과 시간을 셈
		if (started)
		{
			++elapsedSec;
		}
		long long avg = started ? now / elapsedSec : 0;
		printf("[AcceptExServer] 연결완료 tps=%lld avg=%lld total=%lld\n", now - last, avg, now);
		last = now;
	}
}

void AcceptExServer::stop()
{
	if (!mRunning)
	{
		return;
	}

	mRunning = false;
	for (size_t i = 0; i < mWorkers.size(); ++i)
	{
		PostQueuedCompletionStatus(mIocp, 0, 0, nullptr);
	}
	for (std::thread& t : mWorkers)
	{
		t.join();
	}
	mWorkers.clear();
	mStatThread.join();	// statLoop는 Sleep(1000) 끝나는 시점에 mRunning 보고 빠져나감

	closesocket(mListenSock);
	CloseHandle(mIocp);
}

AcceptExServer::~AcceptExServer()
{
	stop();
}
