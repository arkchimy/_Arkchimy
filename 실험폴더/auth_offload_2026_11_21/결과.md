# 인증 분산이 게임 서버에서 줄인 것 - 한 PC A/B (PC B, 2026-11-21)

## 무엇을 비교했나

- A = 지금 구조
  - 로그인 서버가 비밀번호 확인과 RSA를 맡는다
  - 게임 서버는 입장마다 DB 스레드에서 Redis GET + 풀기 + DEL만 한다
- B = 게임 서버가 인증까지 하는 구조를 흉내(`ARK_EMULATE_AUTH=1`, `emulate_auth.patch`)
  - 게임 서버 워커가 입장마다 로그인 서버와 같은 일을 더한다
  - Hello 때 서버 고정 키 서명 1번
  - 입장 요청 때 비밀 키 연산 3번 + Argon2id(64MiB·2회) + 두 입장마다 키 쌍 만들기
  - 요청 풀기·AuthAck 풀기는 비용이 같은 비밀 키 서명으로 대신했다(0.51 대 0.51ms,
    `login_game_profile_pcb_2026_11_21`). MySQL 해시 읽기(0.32ms)는 넣지 않았다
- 부하(한 회 3분)
  - 채팅 봇 30개 예열 60초 → 입장 폭주 봇 100개 60초 → 회복 60초
  - 입장 폭주 봇 = 입장하자마자 끊고 바로 다시
  - 폭주 계정은 미리 가입시키고 게임 계정 행도 만들어 두었다(측정에 가입 해시·첫
    입장 INSERT가 섞이지 않게)
- 순서는 A1 → B1 → A2 → B2, 22:57–23:12
- 볼 값
  - 게임 서버 CPU(1초마다 코어 수)와 메모리 최대
  - 이미 들어와 있는 채팅 봇의 채팅 왕복 시간(보낸 때 → 방송을 받은 때)
  - 폭주 입장 수
- 조건: 서버·봇·MySQL·Redis가 PC B 한 PC(루프백). 두 서버 모두 워커 2. 4회 모두
  봇 판정 PASS(예상밖끊김·프로토콜오류·인증실패 0), 서버 잘못된패킷·DB실패 0

- 회복 구간에도 채팅 봇이 30–90초마다 끊고 다시 들어온다. B는 그때마다 해시를 해서
  CPU가 남는다(B2 회복 첫 5초 p99 1.2초는 폭주 끝의 남은 입장)

## 해석

- **게임 서버가 덜게 된 일**: 지금 구조에서 게임 서버는 입장이 초당 약 20번 몰려도
  CPU가 0.006코어 이하로 그대로다. 같은 입장을 게임 서버가 인증까지 하면 워커 2개가
  거의 다(평균 1.5, 최대 2.0코어) 인증에 쓰인다
- **이미 들어온 사람이 겪는 것**: 인증하는 동안 워커가 다른 일을 못 해 채팅이 그
  뒤에 줄을 선다. 채팅 왕복이 0.35ms → 0.7–0.8초(p50), 가장 늦은 것은 4.8초. 지금
  구조에서는 로그인이 몰려도 게임 서버의 채팅은 그대로였다(가장 늦은 것도 49ms)
- **메모리**: 해시 하나가 64MiB라 워커 2개가 동시에 해시하면 게임 서버가 약 129MB
  더 쓴다(53 → 183MB). 지금 구조에서는 이 메모리가 로그인 서버에만 있다
- **입장 처리량**: B는 게임 서버 워커가 병목이 되어 같은 시간에 입장이 약 26% 적었다
  (1,200 → 885)

## 한계

- 한 PC: B에서는 로그인 서버도 같은 PC에서 해시를 해(폭주 동안 1.6–1.7코어) CPU를
  나눠 쓴다. 실제로 게임 서버가 인증을 맡으면 로그인 서버의 그 일이 없어진다 - B의
  지연에는 CPU 경쟁 몫이 섞였을 수 있다. 게임 서버만 PC B에 두는 두 PC 측정으로 가렸다
  (`two_pc/결과.md`) - 게임 서버 CPU 1.56–1.58코어·메모리 182.5MB로 같은 크기라, 차이는
  CPU 경쟁이 아니라 게임 서버가 떠안은 인증 몫이다. 채팅 p50은 두 PC에서 더 짧았다
  (685–800 → 109–278ms) - 이 부분에는 CPU 경쟁이 섞여 있었던 것으로 본다
- B는 흉내다: 요청·AuthAck 풀기를 서명으로 대신했고 MySQL 해시 읽기가 없다. 게임
  서버가 인증 스레드를 따로 두는 설계라면 워커는 막히지 않지만, 그 스레드의
  처리량·메모리는 같다
- 예열 p50이 B에서 조금 높은 이유(0.39–0.55 대 0.67–0.76ms)는 확인하지 않았다
- 측정 전 CPU 상위: B2 직전 `cleanmgr` 40%·`ngen` 11%가 돌았다(다른 회는 17% 이하).
  B1과 B2의 값이 비슷해 영향은 작아 보인다
