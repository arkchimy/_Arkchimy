| 태그            | 횟수 | 평균(ms) | 최소(ms) | 최대(ms) |
| --------------- | ---- | -------- | -------- | -------- |

| ├ Entry open    | 316  | 0.004    | 0.002    | 0.085    |
| ├ Redis DEL     | 316  | 0.126    | 0.063    | 0.481    |

- `Entry account`의 평균은 두 길이 섞인 값이다(계산 값, 태그로 나누지 않았다)
  - 계정은 한 번 올리면 메모리에 남는다 - DB를 읽는 입장은 봇마다 첫 입장 30번뿐
  - 나머지 286번은 메모리만(최소 1.1us)
  - 30번이 합계 3.05초 → 첫 입장 한 번 약 102ms(새 계정 INSERT 트랜잭션 포함)
- 두 번째 입장부터는 Redis GET + 풀기 + DEL + 응답으로 약 0.27ms
  (Entry total − Entry account = 0.268ms)
- 첫 입장 약 100ms가 MySQL 커밋(디스크 쓰기) 때문인지는 확인하지 않았다
